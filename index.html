    How it's measured
    • An AI coding tool leaves a trace in the commit: its signature (Co-authored-by: Claude Opus 5), or a line the author writes on purpose (Assisted-by: Codex (GPT-5), Model: GPT-6. Harness: Codex. in the pull request).
    • Big projects: every active public repository with 10,000+ stars that contains code. Every commit on the default branch is read, with the description of its pull request. Bots other than AI agents are left out.
    • All public: GitHub commit search over all public repositories, estimated from samples.
    • Models are compared only within one tool: Claude Code always names the model, Codex only when the author does, Cursor and Copilot never.
    • Labs are compared only in projects that disclose AI use on purpose, where tools that do not sign are visible too.
    • Every figure covers four complete weeks. Lines: median lines changed per commit. Reverted: share of commits reverted later.
